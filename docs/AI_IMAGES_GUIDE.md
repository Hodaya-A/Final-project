# 🎨 מדריך יצירת תמונות באמצעות AI

## סקירה כללית

הפרויקט תומך כעת ביצירת תמונות אוטומטית למוצרים באמצעות Artificial Intelligence!

## אפשרויות ליצירת תמונות

### 1. יצירת תמונה בודדת (בטופס הוספת מוצר)

כאשר את מוסיפה מוצר בודד:

1. הזן את שם המוצר וקטגוריה
2. לחץ על כפתור **"✨ צור תמונה באמצעות AI"**
3. התמונה תיווצר אוטומטית ותופיע בשדה כתובת התמונה

### 2. יצירת תמונות בהמוני (בהעלאת קובץ Excel)

כאשר את מעלה קובץ Excel עם מוצרים:

1. בחר קובץ Excel
2. לחץ על "העלאה"
3. במודל שמופיע, **סמן את האופציה** "✨ צור תמונות אוטומטית באמצעות AI"
4. בחר "עדכון מלאי קיים" או "חידוש מלאי"
5. התמונות ייווצרו אוטומטית לכל המוצרים שאין להם תמונה

## הגדרת OpenAI API

### שלב 1: קבלת API Key

1. היכנס ל-[OpenAI Platform](https://platform.openai.com/)
2. צור חשבון (אם אין לך)
3. עבור ל-[API Keys](https://platform.openai.com/api-keys)
4. לחץ על "Create new secret key"
5. העתק את המפתח (שים לב: לא תוכל לראות אותו שוב!)

### שלב 2: הגדרת המפתח בפרויקט

1. פתח את הקובץ `backend/.env`
2. מצא את השורה:
   ```
   OPENAI_API_KEY=your-openai-api-key-here
   ```
3. החלף את `your-openai-api-key-here` במפתח שקיבלת
4. שמור את הקובץ
5. הפעל מחדש את השרת

### שלב 3: בדיקה

לאחר הגדרת המפתח:

- נסה ליצור תמונה למוצר בודד
- אם זה עובד - מצוין! 🎉
- אם לא - בדוק את הלוגים בטרמינל של השרת

## מחירים

⚠️ **שים לב**: OpenAI DALL-E הוא שירות בתשלום

- **DALL-E 3**: ~$0.04 לתמונה (1024x1024)
- **DALL-E 2**: ~$0.02 לתמונה (1024x1024)

לפרטים מלאים: [OpenAI Pricing](https://openai.com/pricing)

## אלטרנטיבות בחינם

אם אין לך מפתח OpenAI:

- המערכת תשתמש אוטומטית ב-**placeholder images** (תמונות זמניות)
- או תחזור לחיפוש בגוגל (השיטה הקודמת)

## פתרון בעיות

### התמונות לא נוצרות?

1. **בדוק את המפתח**: ודא שה-API key תקין ב-`.env`
2. **בדוק יתרה**: ודא שיש לך יתרה ב-OpenAI account
3. **בדוק לוגים**: עיין בטרמינל של השרת לשגיאות
4. **הפעל מחדש**: הפעל מחדש את השרת אחרי שינוי ב-`.env`

### השירות לא זמין?

אם DALL-E לא זמין או נכשל, המערכת:

1. תנסה אוטומטית fallback לחיפוש בגוגל
2. או תשתמש ב-placeholder images

## תכונות נוספות
