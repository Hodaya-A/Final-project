# Fresh End - Backend System Documentation

## Overview

מערכת ה-Backend של פרויקט Fresh End מהווה את התשתית הלוגיסטית לניהול מלאי ומוצרים בזמן אמת. המערכת מתמקדת באופטימיזציה של שרשרת האספקה עבור מוצרים בעלי תוקף קצר, תוך שילוב טכנולוגיות חיפוש מתקדמות ומערכת התראות חכמה.

## QA and Testing Strategy

הפרויקט נבנה תחת מתודולוגיית פיתוח מונחה בדיקות (TDD) כדי להבטיח אמינות מקסימלית. מערך הבדיקות כולל 40 בדיקות אוטומטיות המכסות 100% מדרישות הליבה והסיכונים הטכניים כפי שהוגדרו באפיון המערכת:

- Integration Testing: אימות תקינות נתיבי ה-API בשילוב עם בסיסי הנתונים MongoDB ו-Firebase.
- Logic & Unit Testing: בדיקת מנגנוני זיהוי מילים נרדפות ותזמון התראות פקיעת תוקף.
- Performance Testing: וידוא עמידה בזמני תגובה של עד 7 שניות תחת עומסי שליפת נתונים.
- Data Integrity: אימות מבנה הנתונים הגיאוגרפיים ושלמות האובייקטים המוחזרים מהשרת.

## Core Technologies

- Runtime Environment: Node.js (ES Modules support).
- Web Framework: Express.js.
- Database Management: MongoDB בשילוב Mongoose לניהול המלאי והמשתמשים.
- Notification Service: Firebase Firestore לניהול שירות ההתראות בזמן אמת.
- Testing Framework: Jest בשילוב Supertest.

## API Endpoints Reference

כלל הנתיבים להלן עברו בהצלחה את מערך הבדיקות האוטומטי (40/40 PASS):

### Inventory and Products

- GET /api/products - שליפת כלל המוצרים הפעילים כולל נתוני כתובת ומיקום גיאוגרפי.
- GET /api/products?q={query} - חיפוש טקסטואלי חופשי התומך בתווים מיוחדים ובמנוע מילים נרדפות.
- POST /api/inventory - הוספת מוצר חדש הכוללת ולידציית תקינות מחיר ושדות חובה.
- PUT /api/inventory/:id - עדכון פרטי מוצר קיים כגון מחיר וכמות מלאי.
- DELETE /api/inventory/:id - הסרת מוצר מהמערכת (נתיב מוגן בהרשאות מנהל בלבד).

### Orders and Analytics

- POST /api/orders - יצירת הזמנה חדשה כולל מנגנון הגנה מובנה מפני רכישות כפולות.
- GET /api/analytics - שליפת נתונים סטטיסטיים עבור ממשק הניהול.

## Resource Management

כחלק מהעמידה בדרישות התחזוקה והיציבות שהוגדרו בדו"ח האלפא (עמ' 16), הוטמע מנגנון Teardown מלא בכל הרצת בדיקות. המערכת מבצעת סגירה מפורשת של חיבורי ה-Mongoose וה-Server Handles בתום כל סשן ריצה. פעולה זו מבטיחה מניעת נזילות זיכרון (Memory Leaks) ושימוש יעיל ואופטימלי במשאבי השרת.
